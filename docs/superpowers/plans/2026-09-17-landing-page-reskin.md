# Landing Page Reskin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Reskin `academix`'s marketing site (`app/**`, `components/landing/**`) to visually match the dashboard's design system — same colors, same font, same button/card language — replacing its current dark, soft-SaaS-template look.

**Architecture:** Pure class/value substitution guided by a fixed color-mapping table, applied file by file. No layout, copy, or JS-behavior changes. The two exceptions to "Tailwind class swap" are `app/layout.tsx` (needs new font loading, not just a class change) and `signup/page.tsx` (uses `styled-components` theme constants, not Tailwind classes).

**Tech Stack:** Next.js 14 App Router, Tailwind CSS, styled-components (one file only).

**Spec:** `docs/superpowers/specs/2026-09-17-landing-page-reskin-design.md`

## Global Constraints

- No copy/content changes anywhere, including the placeholder "Feature 1"–"Feature 6" text.
- No section order or layout-structure changes.
- No JS behavior changes (video modal, mobile menu toggle, AOS animations, newsletter form, banner dismiss, signup's own dark-mode toggle).
- No changes to the dashboard side (`pages/`, `components/` outside `landing/`, `templates/`) at all.
- The `land-sm`/`land-md`/`land-lg`/`land-xl`/`land-2xl` **screens** (breakpoint) keys in `academix/tailwind.config.ts` are untouched — do not rename or remove them, and do not touch any `land-sm:`/`land-md:`/`land-lg:`/`land-xl:`/`land-2xl:` responsive-variant usage in any file.
- Every commit message ends with the author's own name only — no `Co-Authored-By`/`Claude-Session` trailer (standing project preference).
- `npm run build` is not a usable pass/fail gate on this codebase — it fails on pre-existing, unrelated issues (see prior ledger/spec history). Use `npm run dev` + manual page checks as verification.

## Color/style mapping reference (used throughout)

| From | To | Role |
|---|---|---|
| `bg-lgray-900` | `bg-background` | page background |
| `bg-lgray-800` (as a background) | `bg-white` | card/surface background |
| `bg-lgray-800`/`text-lgray-800` (as a text/icon color) | `text-n-1` | dark text/icon |
| `text-lgray-100`, `text-lgray-200`, `text-lgray-300` | `text-n-1` | headings, emphasized/label text |
| `text-lgray-400` | `text-n-3` | secondary/muted body text |
| `text-lgray-600` | `text-n-3` | hover state on icons |
| `text-lgray-700` | `text-n-3` | tertiary text |
| `border-lgray-700`, `border-lgray-800` | `border-n-1` | section/card dividers |
| `bg-slate-800` | `bg-white` | (banner.tsx only — uses Tailwind's default slate, not lgray) |
| `text-slate-50` | `text-n-1` | (banner.tsx) |
| `text-slate-500` | `text-n-3` | (banner.tsx) |
| `bg-lpurple-600`, `text-lpurple-600`, `fill-lpurple-600` (strong/default) | `bg-purple-1`, `text-purple-1`, `fill-purple-1` | primary accent |
| `bg-lpurple-700`, `hover:bg-lpurple-700`, `hover:text-lpurple-700` (hover/darker) | `bg-purple-2`, `hover:bg-purple-2`, `hover:text-purple-2` | primary accent, hover state |
| `lpurple-100`–`lpurple-500` (pale/decorative) | `purple-3` | light accent |
| `bg-green-200`, `text-green-600` (badge) | `bg-green-1 text-n-1` | badge |
| `text-green-500` (checkmarks) | `text-green-1` | icon accent |
| `font-inter` | `font-sans` | body font |
| `font-architects-daughter` | *(remove the class — falls back to `font-sans`)* | decorative label font, not part of the dashboard's type system |
| `tracking-land-tight` | *(remove the class — falls back to default tracking)* | |
| `text-land-lg` | `text-lg` | |
| `text-land-xl` | `text-xl` | |
| `rounded-sm`, `rounded` on buttons/inputs | *(remove the class)* | dashboard buttons/cards have sharp corners |
| `rounded-full` | unchanged | inherently circular elements (avatars, icon buttons) — not part of this change |
